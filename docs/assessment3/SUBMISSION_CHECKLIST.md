# Assessment 3 submission checklist

The student must check the LMS's final submission fields and instructions. A code ZIP alone does not satisfy the required walkthrough video.

## Prepared technical work

- Database-backed reporting dashboard and CSV, current inventory, generation outcomes, visible time, filters, alerts and health indicators.
- Persistent word/configuration model with Unicode phonemes and history surviving deletion.
- Wordle and Word Search preview/download plus tested gameplay controls.
- Production browser, persistence, JMeter and Lighthouse tooling, documented measured results and GitHub workflow artifacts.
- Docker application and persistent-volume configuration.
- README and at least five APA 7 industry sources.

## Student actions before submitting

- Record the required 3–8 minute video, showing your face and providing narration throughout; show your actual Student ID within the first 30 seconds.
- Demonstrate dashboard/reporting, real saved CRUD, both downloadable outputs, health and actual Playwright/JMeter/Lighthouse results. Show GitHub homepage and commits.
- Submit the official AI acknowledgement according to the unit's Assessment 3 requirements. An acknowledgement submitted for Assessment 2 may not cover Assessment 3.
- Watch the complete exported video and confirm sound, legibility, duration and required ID/face coverage.
- Include the repository/branch link and upload video, ZIP and supporting files in the fields required by the LMS.
- Confirm the source archive excludes `node_modules`, `.next`, secrets, databases and browser caches. Include both schema migrations and `package-lock.json`.
- Retain the raw evidence archive; GitHub workflow artifacts have limited retention.
